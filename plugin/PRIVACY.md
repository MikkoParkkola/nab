# Privacy

nab can read cookies stored by the local browser so a fetch can reuse a session you already have. A named session stores its cookies on this machine. Cookie values are not sent to the author. Fetching stays on this machine. Searches and fetches go to the URL you asked for, not to a service run by the author.
