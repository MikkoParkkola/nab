# nab v1.0.0 Changelog Draft

> This is a draft for the v1.0 stable release. All features since v0.4.0 are listed.
> Prerequisites: A1 (public API audit), A2 (NabError), A3 (unwrap removal) -- all completed in v0.6.0.

## [1.0.0] - TBD

### Stability

This is the first stable release of nab. The public API surface has been audited and reduced
to a stable subset. All public functions return typed `NabError` variants instead of opaque
`anyhow::Error`. Library code contains zero `unwrap()`/`expect()` calls.

### Added (cumulative since v0.4.0)

#### MCP Server (8 tools)
- **Query-focused extraction** (`focus` parameter) -- BM25-lite scoring extracts only relevant sections
- **Token budget enforcement** (`max_tokens` parameter) -- structure-aware truncation that never splits mid-block
- **Prefetch link graph** (`prefetch_links` parameter) -- same-site link extraction with eTLD+1 filtering
- **Persistent named sessions** (`session` parameter) -- LRU eviction (32 slots), cookie seeding, pinned browser profiles
- **CSS extractor plugins** -- define site extractors in `plugins.toml` using CSS selectors, no Rust required
- **MCP protocol 2025-11-25** -- upgraded from 2025-06-18 via rust-mcp-sdk 0.9
- **URL elicitation** for OAuth/SSO login flows (Google, GitHub, Microsoft, Apple, Facebook, +8 providers)
- **Task-augmented execution** for `fetch_batch` -- immediate return with task ID, background push notifications
- **Multi-select cookie elicitation** -- pick multiple browser cookie stores at once
- **Structured content** (`structured_content`) on all 8 tools alongside human-readable text
- **Output schemas** (`outputSchema`) on all 8 tools
- **Tool annotations** on all 8 tools (read_only_hint, destructive_hint, open_world_hint)
- **Server icons** in light and dark themes
- **Extraction quality scoring** -- `QualityScore` with 4 weighted signals (density, structure, completeness, encoding)

#### Content Extraction
- **Google Workspace provider** -- Docs (markdown), Sheets (table), Slides (text) via browser cookies
- **OOXML comment/suggestion extraction** for Google Workspace documents
- **HTML noise stripping pipeline** -- hidden sections, cookie banners, newsletter signups, base64 URIs
- **Readability/direct fallback** -- automatically picks whichever produces richer output
- **Image and PDF handlers** -- `ImageHandler`, `PdfLightHandler` (no-pdfium fallback)
- **WebMCP discovery** -- `/.well-known/mcp.json` and HTML `<link>` detection

#### Site Rules Engine
- **Config-driven TOML site rules** with embedded defaults and user overrides
- **Template filters**: `|uppercase`, `|lowercase`, `|truncate:N`
- **Per-domain rate limiting** for batch fetch
- **Environment variable authentication** and fallback chains
- **Reddit, StackOverflow, GitHub Issues, Instagram, HackerNews** rule providers
- 6 superseded hardcoded providers replaced with TOML rules

#### WASM Provider Marketplace (feature-gated)
- **Sandboxed WASM extractors** via wasmtime -- zero-trust (no FS, no network, fuel-metered)
- **CLI**: `nab provider list/install/remove/test`
- **Provider manifest format** with URL pattern matching and hot-reload

#### Transcription
- **Parakeet.cpp** as default backend with GPU/FP16
- **Qwen3-ASR** via vLLM -- 4x faster, 30 languages

#### CLI
- `nab context` command for piping clean content to LLMs
- `nab rules list/export` for site rule management
- `nab fetch --json` with confidence scores and quality breakdown

### Changed

#### API Stability (v0.6.0 audit)
- **Public API surface reduced** -- 13 internal re-exports removed, internal modules `#[doc(hidden)]`
- **`NabError` typed error hierarchy** with 9 semantic variants replaces `anyhow::Error` at boundaries
- ~10 `unwrap()`/`expect()` in library code replaced with proper error propagation
- Config structs replace positional parameters across all `cmd/` functions (10 structs)

#### Codebase Quality
- 5 monolithic files decomposed into focused submodules (linkedin, rules/provider, rules/config, cookies, MCP tools)
- 6 shared helpers consolidated (cookie resolution, domain extraction, referer building)
- UTF-8 truncation panics eliminated across cmd/ layer (`floor_char_boundary`)
- Dependencies upgraded: reqwest 0.12->0.13, scraper 0.22->0.25, zip 2->8, chromiumoxide 0.7->0.9
- Rust 2024 edition, MSRV 1.93

### Fixed
- Silent test bug: `concurrent_fetch_custom_item_limit` used wrong TOML field
- SPA command status messages moved from stdout to stderr
- JS-rendered Next.js SPA pages and Ghost CMS extraction
- X Articles full content extraction
- Windows release builds (cross-compilation, feature gating)
- LinkedIn profile extraction via `<code>` JSON (Voyager API deprecated)
- AES-CBC IV correction for cookie decryption

### Removed
- 6 superseded hardcoded site providers (replaced by TOML rules)
- `output_body` parameters and dead `no_spa` field
- Stale `clippy::too_many_lines` suppressions

### Migration Guide
- Public API types reduced from ~44 re-exports to ~20 stable exports
- Error handling: match on `NabError` variants instead of downcasting `anyhow::Error`
- All `cmd_*` functions now take config structs instead of positional parameters
