## Phase 1: Token Economy (Features 2 + 3)

### T1.1: Query-focused extraction module
- **New file**: `src/content/focus.rs`
- **Impl**: Section splitter (heading boundaries), BM25-lite scorer (strip markdown URLs before tokenization), top-20%/min-3/max-10 filter, omitted-section markers
- **AC**: AC1-AC6 from design doc. Benchmark: <5ms for 500 sections.
- **LOC**: ~120 + ~60 tests

### T1.2: Token budget enforcement module
- **New file**: `src/content/budget.rs`
- **Impl**: Block parser, priority scoring (P0-P4, 30% heading cap), structure-aware truncation, `STRUCTURED_CONTENT_MAX_CHARS` const
- **AC**: AC1-AC7 from design doc. Benchmark: <2ms for 200KB.
- **LOC**: ~80 + ~50 tests

### T1.3: Wire focus + budget into FetchTool
- **File**: `src/bin/mcp_server/tools.rs`
- **Change**: Add `focus` and `max_tokens` params to `#[mcp_tool]`. Call `focus::extract_focused` then `budget::truncate_to_budget` in pipeline. Update `build_fetch_structured` for new fields.
- **File**: `src/bin/mcp_server/main.rs` — update `fetch_output_schema()` with `omitted_sections`, `truncated`, `full_tokens`
- **AC**: Combined focus+budget works. Absent params = no change. Site provider URLs also processed.
- **LOC**: ~35

### T1.4: Diff marker exemption in focus scoring
- **File**: `src/content/focus.rs`
- **Change**: Lines containing `[changed]`, `[added]`, `[removed]` diff markers are always kept regardless of BM25 score.
- **AC**: `diff=true` + `focus="query"` retains diff markers in output.
- **LOC**: ~10

**Commit**: "feat: query-focused extraction and token budget enforcement"

### T2.3: Output schema update for linked_pages
- **File**: `src/bin/mcp_server/main.rs`
- **Change**: Add `linked_pages` array to `fetch_output_schema()`.
- **LOC**: ~30

**Commit**: "feat: prefetch link graph with same-site policy and per-host concurrency"

## Phase 3: Persistent Sessions (Feature 5)

*Can run in parallel with Phase 2.*

### T3.1: Session store module
- **New file**: `src/session.rs`
- **Impl**: `SessionStore` with `HashMap<String, SessionEntry>` + `RwLock`. LRU eviction (32 max, `last_used` timestamp). Pinned `BrowserProfile` per session. Cookie seeding via synthesized `Set-Cookie` headers (not raw `Cookie:` header).
- **AC**: AC1-AC7 from design doc. Session name validation. Thread-safe under concurrent calls.
- **LOC**: ~100 + ~60 tests

### T3.2: Wire sessions into fetch/submit/login tools
- **File**: `src/bin/mcp_server/tools.rs`
- **Change**: Add `session` param to `FetchTool`, `SubmitTool`, `LoginTool`. When set, use session client instead of global `get_client()`.
- **AC**: Login→fetch with same session preserves auth cookies. Absent param = no change.
- **LOC**: ~40

**Commit**: "feat: persistent named sessions with LRU eviction and profile pinning"

## Audit Phase: Path to 1.0

*Starts after v0.5.0 ships and runs in production for ~2 weeks.*

### A1: Public API Surface Audit

#### TA1.1: Mark internal modules pub(crate)
- **Files**: `src/lib.rs`, ~8 internal modules
- **Change**: `pub mod arena` → `pub(crate) mod arena`. Same for: `js_engine`, `fetch_bridge`, `annotate`, `analyze` (CLI-only modules). Keep public: `content`, `site`, `http_client`, `auth`, `fingerprint`, `ssrf`, `login`, `form`, `plugin`.
- **Risk**: breaks downstream crate consumers (if any). Mitigate: check crates.io reverse deps first.
- **LOC**: ~20

#### TA1.2: Reduce re-exports to stable API
- **File**: `src/lib.rs`
- **Change**: Remove re-exports of internal types (`StringInterner`, `ResponseArena`, `FetchClient`, `inject_fetch_sync`). Keep: `AcceleratedClient`, `SafeFetchConfig`, `ContentRouter`, `SiteProvider`, `SiteRouter`, `LoginFlow`, `CredentialRetriever`, `BrowserProfile`, `SnapshotStore`.
- Target: 44 re-exports → ~20 stable re-exports.
- **LOC**: ~20

### A2: Error Type Hierarchy

#### TA2.1: Create NabError enum
- **New file**: `src/error.rs`
- **Impl**: `#[derive(thiserror::Error)] pub enum NabError` with variants: `InvalidUrl`, `SsrfBlocked`, `ProviderError`, `ConversionError`, `AuthError`, `LoginError`, `SessionError`, `NetworkError`, `BudgetExceeded`.
- **LOC**: ~60

#### TA2.2: Convert library boundaries from anyhow to NabError
- **Files**: `src/http_client.rs`, `src/site/mod.rs`, `src/content/mod.rs`, `src/auth/`, `src/ssrf.rs`, `src/login.rs`, `src/session.rs`
- **Change**: Public functions return `Result<T, NabError>` instead of `anyhow::Result<T>`. Internal code keeps `anyhow`, converts at module boundaries with `impl From<anyhow::Error> for NabError`.
- **LOC**: ~140

### A3: Unwrap/Panic Removal

#### TA3.1: Replace unwrap/expect in library code
- **Files**: `src/http_client.rs` (19), `src/auth/cookies.rs` (20), `src/site/linkedin.rs` (19), `src/content/readability.rs` (11) — total ~69 sites
- **Change**: Replace with `?`, `.ok_or_else(|| NabError::...)`, or `.unwrap_or_default()` as appropriate. Keep `expect()` in startup-only paths and tests.
- **LOC**: ~60

### A4: v1.0.0 Release

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Site provider pipeline refactor causes regressions | Medium | High | Run all 856 tests before/after P0. Compare provider outputs byte-for-byte. |
| `addr` crate adds unexpected compile time or binary size | Low | Low | ~50KB pure Rust. Benchmark compile time before merging. |
| BM25 focus threshold doesn't achieve 10x on real pages | Medium | Medium | Test against 5 real doc sites in T1.1. Adjust cap if needed. |
| Session LRU eviction drops active sessions unexpectedly | Low | Medium | Log eviction events. 32 slots is generous for typical MCP usage. |
| CJK token budget 60% underestimate causes user complaints | Low | Low | Document limitation. v1.1 can add char-range detection. |
| Public API audit breaks downstream consumers | Low | High | Check crates.io reverse deps before A1. Semver: 0.5→1.0 allows breaking. |
