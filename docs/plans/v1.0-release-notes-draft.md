# nab v1.0.0 Release Notes — DRAFT

## Token-Optimized HTTP Client for LLMs

nab fetches any URL as clean markdown, optimized for LLM context windows. It ships as a standalone CLI, an MCP server (8 tools), and a Rust library with a stable public API.

## Highlights

**Stable API.** The public API surface has been audited and frozen. All public functions return typed `NabError` variants. No more `unwrap()` panics in library code. This is the API you can depend on.

**8 MCP Tools.** `fetch`, `fetch_batch`, `submit`, `login`, `auth_lookup`, `fingerprint`, `benchmark`, and `validate` -- all with structured content output, output schemas, and tool annotations per MCP protocol 2025-11-25.

**Smart Extraction.** Query-focused extraction (`focus` parameter) uses BM25-lite to keep only relevant sections. Token budget enforcement (`max_tokens`) truncates structure-aware without splitting code blocks or tables. Prefetch link graph follows same-site links and merges results. Extraction quality scoring gives LLMs a confidence signal.

**40+ Site Providers.** Config-driven TOML rules for Reddit, HN, GitHub, StackOverflow, Instagram, LinkedIn, Google Workspace (Docs, Sheets, Slides), and more. WASM provider marketplace (feature-gated) for community-contributed extractors running in a zero-trust sandbox.

**Authentication Everywhere.** Browser cookie decryption (Brave, Chrome, Firefox, Safari), 1Password integration, environment variable auth, OAuth/SSO URL elicitation, persistent named sessions with LRU eviction.

## Installation

```bash
# Homebrew
brew install nab

# Cargo
cargo install nab

# Cargo with WASM providers
cargo install nab --features wasm-providers

# Binary download
curl -L https://github.com/MikkoParkkola/nab/releases/latest/download/nab-$(uname -m)-apple-darwin -o nab
chmod +x nab
```

## Breaking Changes from v0.4.x

1. **Error types**: Public functions return `NabError` instead of `anyhow::Error`. Match on specific variants:
   ```rust
   match result {
       Err(NabError::SsrfBlocked { url, reason }) => ...,
       Err(NabError::InvalidUrl(msg)) => ...,
       _ => ...,
   }
   ```

2. **Removed re-exports**: `StringInterner`, `ResponseArena`, `FetchClient`, `inject_fetch_sync` are no longer public. Use `AcceleratedClient`, `SafeFetchConfig`, `ContentRouter` instead.

3. **Config structs**: `cmd_fetch()` and similar functions now take config structs (`FetchConfig`, `SpaConfig`, `StreamCmdConfig`) instead of 10+ positional parameters.
